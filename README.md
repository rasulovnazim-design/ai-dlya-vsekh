# ИИ для всех

Интерактивный курс на русском о том, как пользоваться ИИ-ассистентами и писать хорошие промпты. Для обычных людей в Кыргызстане и Центральной Азии. Статический сайт на GitHub Pages: без сервера, без сборки, без запросов к ИИ.

## Первое, что надо сделать

Откройте `config.js` и впишите:

- `contact.whatsapp`: номер только цифрами с кодом страны, например `996700123456`
- `contact.telegram`: имя пользователя без `@`
- `price`: цену и подпись к ней

Пока контакты пустые, на страницах покупки и обучения для компаний вместо кнопок показывается заметка «Контакт скоро появится».

## Запуск на своём компьютере

Нужен только Node.js. Открывать `index.html` двойным щелчком не получится: браузер не даёт читать файлы контента без сервера.

```bash
node scripts/serve.mjs
```

Сайт откроется на http://localhost:4400. Адрес `localhost` нужен ещё и потому, что проверка кодов работает только на `localhost` и `https`.

## Как редактировать уроки

Откройте файл урока и меняйте текст. Поля:

- `title`: название
- `body`: текст урока. Строка это абзац, `{ "list": [...] }` это список, `{ "note": "..." }` это врезка с советом
- `beforeAfter`: ситуация, слабый и сильный промпт с ответами ИИ, и `why`: одна фраза о том, что изменилось
- `exercise`: упражнение. Тип `prompt`: сценарий, подсказки `hints` к критериям рубрики и образец `sample`. Необязательное поле `skip` убирает критерии, которые здесь не нужны. Тип `choice`: вопрос и варианты с пояснениями

Чтобы добавить урок: создайте файл и впишите его имя в `lessons` нужного модуля в `course.json`.

После правок запустите проверку:

```bash
node scripts/validate-content.mjs
```

Она следит за правилами курса: меньше 300 слов на урок, без длинных тире, звёздочек и разметки, слабый промпт набирает не больше 5 баллов, сильный от 6, образец от 7. Можно проверить один модуль: `node scripts/validate-content.mjs 3`.

## Как настроить проверку промптов

Вся логика оценки лежит в `content/ru/rubric.json`, код менять не нужно. У каждого критерия есть:

- `points`: вес. Итог всегда пересчитывается к шкале из 10, поэтому веса можно менять свободно
- `startsWith`: начала слов. Совпадением считается слово, которое начинается с этих букв: `клиент` найдёт и «клиентке», и «клиентов». Буквы е и ё не различаются
- `regex`: регулярные выражения для более сложных случаев, например «до 80 слов»
- `absent: true`: критерий выполнен, когда таких слов нет. Так устроено «Без лишних слов»
- `taskCount`: сколько разных задач допускается в одном промпте
- `fail`, `pass`, `suggestion`: что увидит ученик

Ещё в файле: `minWords` и `shortCap` (слишком короткий промпт получает не больше такой оценки), `warnings` (предупреждения об ИНН, картах и телефонах, на оценку не влияют), `levels` (заголовки по баллам).

После изменений запустите `node scripts/validate-content.mjs`: она сразу покажет, не сломалась ли оценка примеров из уроков.

Проверка смотрит только на признаки хорошего промпта. Смысл она не понимает: промпт не по теме упражнения, но со всеми нужными частями, получит высокий балл. Для тренировки этого хватает, а настоящую оценку смысла дал бы только запрос к ИИ.

Строки ответа ИИ с разделителем ` | ` сайт показывает настоящей таблицей, первая строка становится шапкой.

## Коды доступа

Модули 1-4 открыты всем. Модули 5-8 и библиотека открываются кодом, который вводится один раз и запоминается в браузере.

Выпустить новые коды:

```bash
node scripts/add-code.mjs 10 "партия для школы №5"
```

Скрипт напечатает коды, запишет их в `codes.local.txt` (этот файл не попадает в git, храните его у себя) и добавит только их хэши в `config.js`. Чтобы коды заработали на сайте, отправьте изменения:

```bash
git add config.js && git commit -m "Новые коды доступа" && git push
```

Отозвать код: удалите строку с его хэшем из `config.js`. Строки помечены датой и подписью, поэтому партию найти легко.

Коды состоят из символов, которые есть в обеих раскладках, поэтому человек может набрать код и кириллицей, и латиницей. Регистр и дефисы тоже не важны.

### Какой тут компромисс

Проверка идёт в браузере, поэтому это замок от честных людей, а не настоящая защита:

- Репозиторий публичный, и все уроки лежат в нём обычными файлами. Платный контент может прочитать любой, кто заглянет в `content/ru/` или в инструменты разработчика.
- Отметку о доступе можно подделать в `localStorage`.
- Один код работает сколько угодно раз на любом числе устройств, а сайт не знает, кто его использует.

В обмен вы получаете бесплатный хостинг, ноль обслуживания и работу без сервера. Для недорогого курса в местном сообществе, где покупают у конкретного человека, это разумная сделка. Если утечки начнут заметно бить по продажам, следующий шаг это небольшой сервер, который отдаёт платные уроки только по проверенному коду. Этот шаг потребует переписать загрузку контента.

## Как добавить кыргызский язык

Сайт уже разделяет текст и код, поэтому перевод это почти только работа с текстом:

1. Скопируйте `content/ru` в `content/ky`.
2. Переведите файлы. Начните с `ui.json` и `course.json`, потом уроки. Если файла на кыргызском ещё нет, сайт покажет русскую версию, так что выкладывать можно по частям.
3. Перепишите `rubric.json` под кыргызский: начала слов в `startsWith` должны быть кыргызскими. Это самая важная часть: просто перевести подсказки недостаточно, иначе проверка не найдёт совпадений.
4. В `plural.lessons` и `plural.prompts` в `ui.json` укажите одно и то же слово трижды: в кыргызском после числа форма не меняется.
5. Добавьте язык в `config.js`:

```js
languages: [
  { code: 'ru', label: 'Русский' },
  { code: 'ky', label: 'Кыргызча' },
],
```

Переключатель языка появится в верхней полосе сам. Заголовочный шрифт Rubik содержит буквы ң, ө и ү. Проверка контента на другом языке: `LANG_CODE=ky node scripts/validate-content.mjs`.

## Публикация

Сайт раздаётся с GitHub Pages из корня ветки `main`. Любой `git push` в `main` публикует изменения через минуту-другую.

Весь прогресс ученика хранится только в его браузере, сайт ничего никуда не отправляет. Формы покупки и обучения для компаний просто открывают WhatsApp или Telegram с готовым текстом.
